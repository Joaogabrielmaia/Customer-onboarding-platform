# Visão do produto e metas de sucesso

**Objetivo:** definir em uma página o que a Trilha é, para quem e como saberei se funcionou.
**Data:** 2026-10-22 · **Status:** concluído
Relacionados: [Problemas priorizados](../01-discovery/08-problemas-priorizados.md) · [Requisitos](02-requisitos.md) · [Escopo](05-priorizacao-e-escopo.md)

## Visão

**Trilha** é uma plataforma web para a equipe da Rota Fácil Software conduzir a implantação do seu sistema nos clientes. Cada implantação nasce de um modelo padrão, com etapas, tarefas, prazos calculados a partir do kickoff e responsáveis. A equipe atualiza o andamento, o fundador enxerga o que está atrasado em uma tela, e o cliente acompanha o progresso por um link, sem criar conta.

| | |
|---|---|
| **Para** | pequenas software houses B2B que implantam sistema em clientes pequenos |
| **Que sofrem com** | implantações em planilha e WhatsApp, sem visão única nem histórico |
| **A Trilha é** | uma plataforma de acompanhamento de implantação |
| **Que** | padroniza o processo, mostra atrasos e dá visibilidade ao cliente |
| **Diferente de** | planilhas e ferramentas genéricas de projeto, porque já nasce com o vocabulário de implantação (kickoff, aguardando cliente, modelo, link do cliente) |

## Problemas atacados

P1 a P7 do [discovery](../01-discovery/08-problemas-priorizados.md). Resumo: atrasos descobertos tarde, combinados perdidos, roteiros diferentes, espera do cliente misturada com atraso da equipe.

## Metas de sucesso (todas HIPÓTESES, nenhuma medida)

> Ainda não há medição. São metas que eu definiria para acompanhar num piloto real.

| ID | Hipótese / meta | Como eu mediria num piloto real |
|---|---|---|
| H1 | O fundador deixa de depender da reunião de segunda para saber o que está atrasado | Perguntar ao fundador e contar quantas vezes abre o painel por semana |
| H2 | As consultas "como está minha implantação?" no WhatsApp diminuem depois do portal | Contar essas mensagens antes e depois do piloto |
| H3 | 100% das implantações novas partem de um modelo padrão | Proporção de implantações criadas com modelo |
| H4 | Os combinados passam a ficar registrados como comentários | Comentários por implantação |
| H5 | O tempo de implantação fica mais previsível | Comparar prazo planejado e real das implantações |
