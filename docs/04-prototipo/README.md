# Episódio 4 — Protótipo

Os wireframes das telas principais foram mostrados ao fundador e à líder de implantação em uma reunião simulada. Saíram oito pedidos: três aceitos, um recusado e quatro adiados, cada um com a justificativa e o impacto no escopo.

O filtro do painel por implantador subiu de Should para Must (RF-18). A recusa mais detalhada é a do cliente marcar tarefa como entregue no portal: o link não tem login, então permitir escrita deixaria qualquer pessoa com o link alterar o andamento (CH-04).
