# Episódio 6 — Treinamento e rollout

Esta fase descreve como a Rota Fácil passaria a usar a Trilha: um piloto com uma implantação nova, critérios para ampliar, um plano de volta para a planilha e os materiais de treinamento e comunicação.

Nada aqui foi executado. A Trilha roda só localmente, e o próprio plano de rollout se declara plano. Os guias para o implantador e para o cliente estão escritos, com prints reais do sistema, mas não houve treinamento com pessoas.
